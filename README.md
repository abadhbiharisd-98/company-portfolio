# BLACK GRAPES — Corporate Company Portfolio (2026 Edition)

An executive, presentation-grade corporate portfolio engineered for **Black Grapes Softech**. Built with React, Vite, Tailwind CSS, and Lucide Icons, formatted specifically as an interactive corporate deck rather than a generic website.

## 🎨 Theme 2 — Light & Clean Professional
- **Background**: Crisp clean white (`#FFFFFF`) with alternating light grey (`#F5F7FA`) sections.
- **Primary Accent**: Professional corporate blue (`#1769FF`).
- **Headings & Hierarchy**: Deep dark navy (`#111827`) with **Poppins** & **Inter** typography.
- **Card Aesthetics**: Pure white surfaces with clean borders (`border-slate-200`), rounded corners (`rounded-3xl` / `rounded-2xl`), and soft corporate elevation shadows (`shadow-soft-sm` / `shadow-soft-hover`).
- **Buttons**: Corporate blue (`bg-brand-600 hover:bg-brand-700`) with subtle hover transitions.
- **Minimal & Corporate**: Retains all 10 presentation sections, deck controls, and data.

## 🚀 Live Access & Development
- **Local Server**: `http://localhost:3000/`
- **Build Production**: `npm.cmd run build`
- **Preview Production**: `npm.cmd run preview`
